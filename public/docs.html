CryptoProject API Documentation

This API provides cryptocurrency data, price alerts, conversions, historical data, and market insights by fetching live data from CoinGecko.

Base URL

https://cryptoproject-bvhy.onrender.com

Endpoints

GET /coins/list

Returns a list of all supported coins with their IDs, symbols, and names.

GET /coins/list

Response: Array of coins:

[
  {
    "id": "bitcoin",
    "symbol": "btc",
    "name": "Bitcoin"
  },
  {
    "id": "ethereum",
    "symbol": "eth",
    "name": "Ethereum"
  },
  ...
]

GET /price/:symbol

Gets the current USD price for a cryptocurrency specified by its symbol.

GET /price/btc

Response:

{
  "symbol": "BTC",
  "price": 27950.32
}

Returns 404 if the symbol is not found.

POST /webhook/price-alert

Check if the price of a coin has changed beyond a threshold since the last check and trigger an alert.

POST /webhook/price-alert
Content-Type: application/json

{
  "symbol": "btc",
  "threshold": 500
}

Response:

{
  "symbol": "btc",
  "currentPrice": 27950.32,
  "alert": true  // true if price changed by threshold or more, else false
}

Returns 404 if the symbol is invalid.

GET /convert

Convert an amount between two cryptocurrencies by symbol using their USD prices.

GET /convert?from=btc&to=eth&amount=2

Response:

{
  "from": "BTC",
  "to": "ETH",
  "rate": 14.5  // 1 BTC equals 14.5 ETH approximately
}

Returns 404 if any symbol is invalid.

GET /history/:symbol

Retrieve 7-day historical market data for a coin, including prices, market caps, and volumes.

GET /history/eth

Response:

{
  "prices": [[timestamp, price], ...],
  "market_caps": [[timestamp, marketCap], ...],
  "total_volumes": [[timestamp, volume], ...]
}

Returns 404 if the symbol is not found.

GET /top/movers

Get the top 5 gainers and top 5 losers based on 24-hour price changes.

GET /top/movers

Response:

{
  "top_gainers": [ /* Array of 5 coins with highest 24h % gain */ ],
  "top_losers": [ /* Array of 5 coins with highest 24h % loss */ ]
}

GET /new/listings

Get the 10 newest cryptocurrency listings by market cap ascending.

GET /new/listings

Response: Array of coin objects.

GET /trending

Get a list of currently trending coins.

GET /trending

Response: Array of trending coin objects.

Usage Example

Fetch the current price of Bitcoin using JavaScript:

fetch('https://cryptoproject-bvhy.onrender.com/price/btc')
  .then(res => res.json())
  .then(data => console.log(`BTC price: $${data.price}`))
  .catch(err => console.error(err));

Notes

  • All prices are in USD.
  • Symbol matching is case-insensitive.
  • Price alerts are based on absolute price difference since last check.
